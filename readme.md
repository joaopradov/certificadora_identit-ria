# 🎓 ELLP — Sistema de Gerenciamento de Escolas Parceiras

Sistema web desenvolvido para centralizar e organizar as informações das instituições participantes do **ELLP**, projeto de extensão da Universidade Tecnológica Federal do Paraná (UTFPR), campus Cornélio Procópio.

## 📌 Sobre o projeto

O ELLP é um projeto de extensão da UTFPR Cornélio Procópio, desenvolvido desde 2014, que atende crianças e adolescentes de escolas públicas, organizações não governamentais (ONGs) e creches.

O projeto surgiu da necessidade de melhorar a organização e o acompanhamento das instituições participantes, centralizando dados de escolas, representantes, alunos atendidos e documentos.

A proposta consiste no desenvolvimento de uma aplicação Fullstack que permita realizar o gerenciamento dessas informações de maneira prática, segura e eficiente.

## 🎯 Objetivo

Desenvolver um sistema web para facilitar o gerenciamento das instituições parceiras do ELLP, proporcionando maior controle, organização e acessibilidade às informações.

### Objetivos específicos

- Centralizar o cadastro das instituições participantes.
- Gerenciar os representantes vinculados às instituições.
- Cadastrar e acompanhar os alunos atendidos.
- Controlar a situação de participação das escolas.
- Organizar documentos, cartas-convite e convênios.
- Automatizar a geração de cartas-convite em PDF.
- Disponibilizar indicadores para acompanhamento das atividades.

## ⚙️ Funcionalidades previstas

### 🔐 Autenticação
- Login de usuários autorizados.
- Recuperação de senha.
- Controle de acesso ao sistema.

### 🏫 Gerenciamento de escolas
- Cadastro, consulta e edição de instituições.
- Registro de informações de contato e localização.
- Controle da situação de participação.
- Busca e filtros por situação.
- Vinculação de representantes.

### 👥 Gerenciamento de alunos
- Cadastro e edição de alunos.
- Vinculação dos alunos às instituições.
- Registro de série e data de entrada no projeto.
- Controle da situação dos alunos.

### 📄 Gerenciamento de documentos
- Registro de cartas-convite e convênios.
- Acompanhamento do status dos documentos.
- Geração de cartas-convite em PDF.
- Consulta e organização dos arquivos.

### 📊 Dashboard
- Quantidade de instituições participantes.
- Total de alunos atendidos.
- Quantidade de documentos pendentes.
- Visualização das últimas escolas cadastradas.
- Atalhos para as principais operações.

## 🗂️ Estrutura do projeto

A aplicação será organizada em duas partes principais:

- **Front-end:** responsável pela interface, navegação e interação com os usuários.
- **Back-end:** responsável pelas regras de negócio, autenticação, gerenciamento dos dados, integração com o banco de dados e geração de documentos.

## 🔒 Segurança e proteção de dados

Considerando que o sistema gerenciará informações de crianças e adolescentes, o projeto prevê cuidados com a privacidade e a proteção dos dados pessoais, observando os princípios da Lei Geral de Proteção de Dados Pessoais (LGPD).

Entre os cuidados previstos estão a coleta mínima de informações, autenticação de usuários e restrição de acesso aos dados.
